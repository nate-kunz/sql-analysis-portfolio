# SQL-Analysis-Portfolio
This repository reorganizes my DAD-220 (SNHU) coursework around core SQL fundementals. During this course, I built a relational MySQL database from scratch with primary/foreign keys, bulk CSV data loading, CRUD operations, joins, schema refactoring, and analytics queries.

## Portfolio Focus

This portfolio demonstrates:

- Database and table creation
- Data types, primary keys, foreign keys, and table relationships
- Manual data insertion
- CSV imports using `LOAD DATA INFILE`
- Data validation using `SHOW`, `DESCRIBE`, `DESC`, and `SELECT`
- Filtering, counting, grouping, ordering, and limiting query results
- Inner joins and multi-table joins
- Views, table renaming, column renaming, and constraint updates
- Update and delete operations
- CSV/file exports using `INTO OUTFILE`
- Analytical SQL for sales, returns, regional performance, and fleet maintenance patterns
